# 已验证的电费查询协议

本记录来自本地 APK 与自己宿舍的抓包，不包含登录凭据和真实宿舍编号。

## 请求

```text
POST https://mcard.sdu.edu.cn/charge/feeitem/getThirdData
Content-Type: application/x-www-form-urlencoded
synjones-auth: bearer <TOKEN>
```

| 表单字段 | 内容 |
| --- | --- |
| `feeitemid` | `411`，威海电控缴费项目 |
| `type` | `IEC`，查询剩余电量 |
| `level` | `4`，已选定房间 |
| `campus` | 抓包得到的校区值 |
| `building` | 抓包得到的楼栋值 |
| `floor` | 抓包得到的楼层值 |
| `room` | 抓包得到的房间值 |

选择项的值通常包含 `编号&显示名称`；不要仅凭页面文字自行拼接。
同一接口的 `type=select`、`level=0..3` 用于逐级获取校区、楼栋、楼层、房间。
当前脚本直接使用已选房间的参数，无需每次遍历列表。

## 响应与解析

已捕获且直接查询得到的核心响应：

```json
{
  "msg": "success",
  "code": 200,
  "map": {
    "showData": {
      "信息": "剩余电量为35.67度，供电状态：查询失败"
    }
  }
}
```

剩余电量取自 `map.showData.信息`，以十进制数保存。35.67 度对应 35.67 kWh。
供电状态单独保存；其中的“查询失败”不否定同一响应中明确返回的剩余电量。
没有电量字段、非 JSON、HTTP/业务错误都会记录为失败，不会转换为零电量。

## 认证与限制

现场验证结果：携带 `synjones-auth`、省略 Cookie 和 Authorization 仍返回正确电量；
完全省略认证则返回 HTTP 401。因此正式查询仅保留所需 Token 和普通请求头。
当前未发现需要重放动态请求签名；此结论仅针对已验证的余额查询。

Token 的 `exp` 是未验签读取的声明，仅作为到期提示。是否还能登录以学校接口响应为准，
退出登录或服务端撤销可能导致提前失效。尚未实现自动登录或自动刷新 Token；
凭据失效时重新从 App 抓包导入。登录抓包可能包含个人数据，留在本地即可。

本机关闭抓包代理、手机断开后，Python 与 Rust 都应通过直接 HTTPS 请求运行。
其他部署网络的可达性需在目标机器上单独验证；不据本机成功推断任意网络可用。
